# 「再开一局 2026」双轨经济、8×8 俱乐部基建、PA 潜力、青训营与转会市场完整设计方案

> 本文档为系统级重构与拓展设计蓝图，涵盖经济体系拆分、纯俱乐部基建（8 部门 × 8 级）、PA 潜力全链路实装、青训营（刷小妖 + 两段迷雾探查）、转会市场（动态身价 + 卖人/买人 + 金币赌博）以及配套美术资源评估。

## 一、核心设计原则：双轨经济拆分

将原本一次性消耗的 `draft.budgetRemaining` 升级为跨赛季持久化的 **俱乐部资金 (`clubFunds`)**，与教练个人肉鸽点数 **PT (`metaPointsTotal`)** 彻底分工：

| 货币 | 定位 | 核心收入来源 | 核心支出出口 |
| :--- | :--- | :--- | :--- |
| **俱乐部资金 (`clubFunds`)** | 俱乐部经营与球员流转货币（起始 `2080 + 财政基建加成`） | 1. 开局选秀结余留存<br>2. 每轮常规赛胜/平/负门票奖金（随联赛等级与球场基建放大）<br>3. 赛季末排名转播分红与结余利息<br>4. **转会市场卖出球员收入** | 1. 初始选秀签人<br>2. **8 大俱乐部基建部门升级**<br>3. 青训营试训付费刷新、一/二阶迷雾探查、签字费<br>4. 转会市场买入球员、付费刷新<br>5. **3 种金币对赌（黑市盲盒 / 海外试训包 / 私人魔鬼特训）** |
| **教练 PT (`metaPointsTotal`)** | 教练个人局外永久成长货币 | 1. 赛季末排名/冲级/冠军结算<br>2. 成就奖励、编年史/剧情事件<br>3. 赛后 3 选 1 / 对赌 | 1. SkillWeb 124 节点技能星图（点亮 / 升阶 / 洗点）<br>2. 阵型/风格战术研习（`30pt`）<br>3. 休赛期常规特训（`10pt`）<br>4. 赛后 3 选 1 保底重抽（`8pt`） |

### 为什么坚持双轨隔离？
1. **消除肉鸽“囤积焦虑”**：如果买人/刷青训与点永久天赋共用同一种钱，理性玩家会舍不得花钱买球星和刮小妖。拆分后，玩家可放心把 `clubFunds` 投入球员流转和青训抽奖。
2. **防止局外数值崩盘**：教练技能树和战力词条依然只锚定 `PT`（战绩/荣誉驱动），避免玩家停留在第 7 级联赛靠刷小妖卖钱就点满全部技能树。

## 二、纯「俱乐部基建」拓展方案（`MetaTree.ts`：8 部门 × 8 级）

**去掉全部教练分支**（教练成长全归 SkillWeb 技能树），将 `MetaTree.ts` 统一改造为 **8 个纯俱乐部基建部门，全部消耗 `clubFunds`**，替代重度建造系统。

### 1. 统一升级成本与联赛阶梯防刷门槛
* **资金阶梯（Lv.1 ~ Lv.8）**：`[180, 320, 520, 800, 1150, 1600, 2200, 3000]`
* **联赛阶梯门槛（记录历史最高达到的联赛级别 `bestTierReached`）**：
  * `Lv.1 ~ Lv.5`：无联赛级别限制，有资金即可升级
  * `Lv.6`：需曾升入 **第 5 级联赛**（`bestTierReached <= 5`）
  * `Lv.7`：需曾升入 **第 3 级联赛**（`bestTierReached <= 3`）
  * `Lv.8`：需曾升入 **第 1 级超级联赛**（`bestTierReached <= 1`）

### 3. `MetaScreen.ts` UI 改造

## 三、PA（潜力上限）全链路实装方案

### 1. 数据结构扩展（`packages/core/src/types.ts`）
```ts
export interface DraftPlayer extends PlayerInput {
  // 现有字段...
  ca: number;
  pa?: number;                // 潜力上限 (45..96)，出生即定，恒有 pa >= ca
  scoutFogLevel?: 0 | 1 | 2;  // 0=完全迷雾, 1=一阶体测, 2=二阶精测/已入队公开
  paEstMin?: number;          // 迷雾状态下的潜力下限预估
  paEstMax?: number;          // 迷雾状态下的潜力上限预估
  isAcademy?: boolean;        // 青训学院出品
  marketValue?: number;       // 动态计算转会估值缓存
}
```

### 2. 生成与旧存档迁移
* **生成规则（`PlayerPool.ts` `generateDraftPlayer`）**：
  * `16~20 岁`：`pa = Math.min(96, ca + randInt(12, 34))`（高成长空间胚子）
  * `21~24 岁`：`pa = Math.min(96, ca + randInt(5, 16))`
  * `25~27 岁`：`pa = Math.min(96, ca + randInt(1, 6))`
  * `28+ 岁`：`pa = Math.min(96, ca + randInt(0, 2))`
* **旧存档迁移（`LeagueManager.migrateState()`）**：对所有 `pa === undefined` 的存量球员按当前 `age` 与 `ca` 自动补齐 `pa`。

### 3. 已入队球员的 UI 展示规范
* **球员卡面（`ClubRosterScreen.ts`、`DraftScreen.ts`、`SeasonEndScreen.ts`）**：
  * 右上角由单行 `CA 74` 升级为双显：**大号 `CA 74`** + 小字 **`PA 86`**（或 **`74/86`**）。
  * 当 `PA - CA >= 12` 时标注青色/金色 **`+12 潜`**；当 `CA >= PA` 时标注暗灰 **`MAX`**。
  * 大名单与选秀排序按钮新增 **「按潜力 PA」**。
* **详情弹窗（`PlayerModal.ts`）**：
  * 头部信息行显示：`19岁 · CA 62 / PA 86 (成长空间 +24) · 估值 ¥145`（未探查迷雾态则显示 `CA ?? / 潜力评估 ★★★☆~★★★★★ (PA 68~88)`）。
  * 增加 **「潜力开发进度条」**：底条总长 `99`，高光外框到 `PA`，实心亮条到 `CA`，直观展示剩余成长空间。

### 4. PA 的 4 条引擎/养成约束
1. **自然成长与常规特训封顶**：季末表现成长、U21 储备队挂机成长、休赛期常规特训（10pt）、赛后属性卡提升，最终 `CA` 严格 `<= PA`。
2. **稀缺破限渠道**：仅高价「私人魔鬼特训」（成功时 `PA +2~3`）、赛季宝箱「青训黄金一代」（`PA +4`）、隐藏特质觉醒可提升 `PA`。
3. **动态身价核心因子**：`PA - CA` 越大且年龄 `<= 22`，转会估值溢价越高。
4. **老将衰退不抹除历史 PA**：30 岁后 `CA` 衰退但保留 `PA` 作为生涯巅峰标尺。

## 四、青训营系统设计（刷小妖 + 迷雾探查 + 梯队练级）

* **开放时机**：休赛期（`SEASON_END` 及未开赛大名单管理期）。
* **试训池刷新**：每次生成 `4` 名 `16~19` 岁青训试训生；优先消耗 `academy` 免费次数，之后使用金币阶梯刷新（`¥60 → ¥100 → ¥160 → ¥240`，受 `scout` 折扣）。
* **两段式迷雾鉴宝**：
  1. **Lv.0 初筛（免费）**：仅见 `年龄 / 位置 / 球风标签` + 模糊 `PA` 区间（受 `scout` 收窄），`CA` 显示 `??`。
  2. **Lv.1 体测（`¥40`，受折扣）**：揭晓 **真实 `CA`**、**3 项核心属性**（`scout >= 4` 多显 2 项）、**是否带隐藏特质**。
  3. **Lv.2 骨龄精测（`¥90`，受折扣）**：揭晓 **精确 `PA` 上限**、**全部 10 维属性** 与 **潜在银/金标**。
* **签约入队**：低廉签字费（`¥35~¥90`，受 `academy` 折扣）签入 40 人大名单，入队后 `PA` 完全公开。
* **U21 储备队练级修正（关键体验优化）**：
  * 修正 `LeagueManager.ts` 季末结算：**40 人大名单中未入选本季 26 人的 `<= 21 岁` 球员不再掉属性，而是触发「U21 梯队锻炼」（每季成长 `+1~+3 CA`，受 `academy` 加成，上限 `PA`）**；一线队踢满 `10+` 场则按表现成长 `+3~+5 CA`。

## 五、转会市场与金币赌博设计

### 1. 动态身价公式 `calcTransferValue(player)`
`估值 = 基础CA价值 × 年龄系数 × 潜力溢价 × 词条与荣誉系数`
* **基础 CA 价值**：随 `CA` 指数增长（`CA 45 ≈ ¥45`，`CA 65 ≈ ¥120`，`CA 80 ≈ ¥260`，`CA 88+ ≈ ¥420+`）。
* **年龄系数**：`16~20 岁 ×1.35`、`21~24 岁 ×1.15`、`25~28 岁 ×1.0`、`29~31 岁 ×0.75`、`32+ 岁 ×0.5`。
* **潜力溢价**：`PA - CA >= 12` 且年龄 `<= 23`，额外 `+15% ~ +30%`。
* **词条与荣誉**：每枚金标 `+12%`，上季进球/助攻/零封突出额外 `+10%`。

### 2. 卖球员双模式（底线校验：卖出后大名单 `>= 26` 人且至少留 `1` 名 GK）
* **快速兜售**：按估值 `85%`（`transfer` 最高提至 `92%`）立即变现。
* **挂牌竞价**：占用挂牌槽位（`3~6` 个），立即生成 `2~4` 家 AI 俱乐部报价（`90% ~ 135%`，高潜 U21 偶发豪门高溢价求购），玩家择优成交。

### 3. 买球员 & 3 种金币对赌（防囤积 Gold Sink）
* **转会货架**：`8~14` 名挂牌球员（混搭即战力与漏网高潜新星），支持付费刷新。
* **3 种高弹性金币赌博（只赌养成资源，不直接赌金币）**：
  1. **黑市神秘推荐信（`¥250` / `¥600` 两档）**：高概率开出普通轮换，小概率开出带金标落魄球星或 S 级小妖，也有概率开出高龄/玻璃人水货（只能折价卖出止损）。
  2. **海外联合试训包（`¥380`）**：一次盲签 3 名未探查 U18 苗子进大名单，适合空位多时豪赌黄金一代。
  3. **高价私人魔鬼特训（`¥350`）**：指定 1 名 U23 赌高强度突破（`55%` 成功 `PA +2~3` 或核心属性 `+3` / `30%` 无提升 / `15%` 轻伤或体能上限 `-1`）。

## 七、老将序章重制、建队流程重排与主客场球衣防撞色

### 1. 序章第一幕（`PrologueScreen.ts` Stage 0）：灯光高度与构图修正
* **问题**：原体积聚光灯束（God Rays）起点 `y = 110`、终点 `y = 580`，光斑打得过于靠下，与底部字幕框重叠。
* **调整**：将聚光灯光源起点上移至通道顶拱门区域（`y = 0 ~ 25`），光束收敛散射至中上区（`y = 320 ~ 390`），浮尘粒子活动区同步上移（`y = 40 ~ 360`），让顶部逆光剪影更通透、底部台词区保持沉稳暗部。

### 2. 序章第二幕：接入真实 2D 比赛最后 15 分钟（剧本模式）
撤除原 `PrologueScreen.ts` Stage 1 的静态缩圈小游戏，改为**无缝切入真实 `MatchDayScreen` + `MatchEngine` 剧本模式**：
1. **75' 切入（1:1 平局，最后 15 分钟）**：
   - 自动构造一场高张力夜雨绝杀战（我方 10 号 37 岁老将登场/持球核心，佩戴金色队长袖标与专属光环）。
   - 跳过冗长赛前 VS 过场（或 0.8s 快速入场），顶部显示 `PROLOGUE · 最后 15 分钟`，隐藏无关的多余加速/快进按钮避免跳坏剧本。
2. **75' ~ 88' 教练手牌实战教学**：
   - 手牌区提供精简教学手牌（包含「老队长的怒吼 / 致命一击」），引导玩家**亲手打出 1 张手牌为老将与前场施加 Buff**，场上立刻出现脉冲光环与属性飘字。
3. **89' ~ 90+2' 必然触发 `0.25x` 子弹时间 + 技能远射破门**：
   - 老将带球推进至禁区前沿，**必然触发 `0.25x` 子弹时间主动技横幅**（「最后一舞 · 远射绝杀」）。
   - 玩家点击 **`立即释放 (F)`** → 播放 `fx_skill_cutin_ult` 横幅 + 顿帧震屏 → 引擎强制执行一脚禁区外远射世界波破门 → `goal_banner` 烟花爆发，比分锁定 `2 : 1`！
4. **终场哨响衔接过场**：
