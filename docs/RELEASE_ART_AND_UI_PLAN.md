# 《FM League · 2026》发行级美术资源、界面设计与交互重规划方案

> 适用范围：`fm-league` 双端同构版本（Steam 桌面端 1280×720 / 2560×1440 + 微信小游戏横屏）
> 制定目的：彻底摆脱当前「纯代码矩形框 + 表单式分栏」的 HTML Demo 质感，对齐商业独立游戏 / 足球转播级视觉与交互标准，并正式启动美术资源清单对接。

---

## 一、为什么现在像 HTML Demo？（核心诊断）

1. **视觉容器过于“后台管理系统”**：大量等距 `drawRoundRect` + `1px` 细边框平铺满屏，缺少**层级景深（全屏场景图 + 暗角遮罩 + 磨砂/金属斜切面板）**与**材质质感（高光斜边、内阴影、微纹理）**。
2. **缺少强视觉焦点（Hero Focal Point）**：标题页、选秀池、赛后结算全靠小字号文本撑场，缺少大尺寸**球星卡、奖杯、故事线漫画分镜、元素指挥卡插画**作为视觉锚点。
3. **字体与排版缺少运动转播张力**：字号集中在 `11~18px`，比分、CA 评分、倒计时未使用大号粗体/斜体运动数字排版。
4. **交互偏“网页表单”而非“游戏手感”**：如建队页像问卷表单、战术换人靠文字按钮、手牌只是小矩形，缺少**翻牌、飞入、拖拽/连线、震屏与粒子反馈**。

## 二、发行级界面视觉重设计（去 HTML 化 4 大法则）

### 2.1 色彩与材质系统升级
* **三层景深结构**：
  * **L0 场景层**：全屏低饱和度暗调插画/球场夜景背景（加 `rgba(6, 10, 18, 0.55)` 压暗遮罩，保证前景文字可读）。
  * **L1 面板层**：**斜切角（Chamfered Corner）+ 顶部高光金属线 + 半透明深空磨砂底**，淘汰千篇一律的圆角矩形边框。
  * **L2 焦点层**：球星卡、指挥卡、奖杯、故事线插画使用高饱和度光效描边与径向聚光。
* **转播级字体层级**：引入等宽运动数字风格（比分/CA/倒计时 `28~48px` 加粗），主标题与副标题拉大对比度。

### 2.2 核心页面重构蓝图

| 页面 | 当前状态（HTML 感来源） | 发行级重构方案 |
| :--- | :--- | :--- |
| **Title 登录建队页** | 左右两栏大表单，像注册页面 | **全屏球场隧道/金字塔主视觉** + 左侧电影感 Logo 与「继续赛季 / 开启新赛季」大主按钮；建队定制收拢为**3 步式轻量向导弹窗**（选图腾配色 → 定队名 → 选哲学），进入即见震撼主画面 |

## 四、交互手感升级方案（代码侧可立即先行）

1. **动效与转场系统（`Tween / Particle` 轻量模块）**：
   * 页面切换 `180ms` 淡入微推过渡，消除硬切闪屏。
   * 选秀签人、卡牌合成、进球时刻触发 **Canvas 粒子爆发 + 数值滚动跳变**。
2. **TitleScreen 去表单化重构**：
   * 主屏只保留震撼视觉、继续当前赛季大卡片、开启新赛季入口、天赋树与荣誉室入口；建队配置收拢为**沉浸式 3 步弹窗向导**。
3. **MatchDay 实体手牌 + 转播悬浮 HUD**：
   * 球场占满视觉中心，底部指挥手牌改为**竖版实体卡牌槽**（带元素色框、费用角标、悬停上浮 `12px` 放大预览）。

## 五、工程对接路线图（4 步落地）

1. **Step 1（资源加载底座）**：在 `@fm-league/game-ui` 新增 `AssetLoader.ts`（支持加载进度、内存缓存、Steam 本地路径 & 微信分包路径映射、资源未就绪时自动回退现有矢量绘制）。
2. **Step 2（去 HTML 化 UI 皮肤升级）**：升级 `CanvasKit.ts`（斜切金属面板 `drawTechPanel`、转播级数字/徽章、粒子系统与页面过渡），重构 `TitleScreen` 为主视觉 + 建队向导。
3. **Step 3（首批 P0 美术资源生成与压缩接入）**：产出并接入 `ART-BG-01~04`、球星卡框、5 大元素徽记，以及精修 `/美术图片/` 中的故事线插画。
4. **Step 4（微信端适配与包体压测）**：搭建 `apps/wechat`（`game.json`、`project.config.json`、安全区与分包加载），实测包体 `< 4MB` 与 60fps 流畅度。
