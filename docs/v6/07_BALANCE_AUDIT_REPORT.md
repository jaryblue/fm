# FM-League V6 玩法平衡性与公平性全量评测报告

> **测试方法论**：全量采用同战力镜像基准（双方均 **72 CA**、零隐藏偏袒、随机主裁与真实物理引擎），通过 8 线程无头 CLI 累计实测 **2,236 场** 全量自动化门禁（`npm run audit:balance`，耗时 34.2 秒）与 **2,320 场** 分阵型×分打法矩阵。

---

## 一、核心结论：没有任何一个流派是“下水道”

在最新一轮 `npm run audit:balance` 中，**15 项自动化平衡性门禁实现 `15 PASS / 0 WARN / 0 FAIL`**：

| 流派（常用搭配） | 前期胜率 / PPG | 中期胜率 / PPG | 后期完全体胜率 / PPG | 下半场技能占比 | 定位与真实强度评价 |
|---|---|---|---|---|---|
| **高位逼抢 (`4-2-3-1`)** | 54.0% / 1.86 | 68.0% / 2.26 | **78.0% / 2.46** | 55.6% | **前期节奏压制型**：开荒期上手快，但 90' 剩余体能全场最低（62.5%），不轮换易在密集赛程吃伤停 |
| **铁桶大巴 (`5-3-2`)** | 36.0% / 1.38 | 50.0% / 1.76 | **66.0% / 2.26** | 60.9% | **后期大核型**：前期偏稳，成型后靠双绝杀护盾+偷鸡反击胜率翻倍 |
| **传控渗透 (`4-3-3`)** | 38.0% / 1.40 | 62.0% / 1.98 | **64.0% / 2.10** | 55.5% | **中后期起飞型**：点亮连传增伤与卫星减费后控制力极强，并非传控弱，而是必须配对渗透/倒三角手牌 |
| **均衡全能 (`4-3-3`)** | 40.0% / 1.42 | 66.0% / 2.14 | **62.0% / 2.10** | 67.3% | **全能稳健型**：无明显短板，下半场容错率与技能留存最高 |
| **防守反击 (`4-3-3`)** | 48.0% / 1.70 | 58.0% / 1.90 | **60.0% / 1.98** | 55.6% | **克制型刺客**：打高压/两翼自带破防红利，专治压上过深的对手 |
| **两翼齐飞 (`4-3-3`)** | 44.0% / 1.60 | 58.0% / 1.98 | **60.0% / 1.98** | 54.5% | **边路轰炸型**：边路进攻占总进球 **30.9%~31.6%**，搭配双锋/高空头球极其暴力 |

> **如何回应“我玩的传控/大巴/两翼太弱”？**
> 1. **“传控/大巴前期刮痧”是故意设计的成长曲线**：前期（1~4 轮）`tiki_taka` 38%、`park_bus` 36%，但到了后期完全体分别跃升至 **64%** 和 **66%**（此前测试上限可达 73%~77%），并非数值弱，而是后期型构筑需要星盘卫星与圣物成型。
> 2. **“高压逼抢无脑强”只看单场不看赛季**：`gegenpress` 90 分钟人均体能消耗比其他流派多掉 **4%~6%**，连续不轮换会导致主力体能跌破 60%（60% 体能胜率会直接腰斩至 **16%**）并触发抽筋/轻伤停。

## 二、机制与生态铁律：全部 273 个星盘节点零死区、AI 零作弊

1. **全节点 100% 实装接线（`0` 死机制）**：
   - **59 个主动技**、**122 张临场指令**、**92 条被动节点**全部接入 `MatchEngine`，未接线节点 = **0**，极端负收益自残指令 = **0**。
2. **玩家 vs AI 完全对称公平**：
   - 9 轮连赛实测：AI 在赛中 **60'~84'** 会自动根据体能与伤病预警做出 **3~4 次换人**（本轮实测 `4` 次），赛后恢复与抽筋/轻伤停判定与玩家保持同一套规则（累计触发 AI 疲惫预警，靠轮换替补维持健康度），不存在“AI 无限满血作弊”。
3. **90 分钟节奏分配合理（告别开局放光技能）**：
   - 所有 6 大流派构筑的 **下半场（46'-90'+）主动技触发占比全部稳定在 `54.5% ~ 67.3%`**，确保上下半场均有关键时刻高光与战术博弈空间。

## 三、真实足球拟真度校验（300 场生态样本）

- **场均总进球**：`3.01` 球（符合高节奏竞技联赛预期）
- **90' 非门将平均体能**：`66.7%`；**赛中轻伤/抽筋事件**：场均 `0.35` 次
- **边后卫真实参与度**：四后卫体系 `LB/RB` 场均传球 **`5.1` 脚**，三后卫体系翼卫 `LWB/RWB` 场均 **`13.7` 脚**
- **8 类进攻手段全面激活**：
  - 边路进攻（下底传中 + 45°斜传 + 倒三角回传）合计占 **`14.4%`**；
  - 定位球（角球争顶/直接任意球）+ 禁区造点合计占 **`8.8%`**；
  - 其余由中路阵地配合、外围远射与直塞单刀共同构成立体进攻。
