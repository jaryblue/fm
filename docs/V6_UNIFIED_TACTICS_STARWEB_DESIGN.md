# 《再开一局》V6 底层驱动「阵型 × 战术 × 交叉演化」大一统星盘设计案

> **核心设计铁律（严格从底层玩法生长，拒绝凭空生编）**：
> 本作的底层足球骨架是 **`3 大防线体系（16 个真实阵型）`** × **`6 大战术打法`** × **`11 种球员职责`**。
> 因此，所有「球队/球员被动」「三区双刃剑指令（取代旧卡牌）」「子弹时间主动技（F 键）」都必须从以下三层因果链自然演化：
> 1. **阵型维度（兵力与空间骨架）**：不同阵型场上有不同的岗位配置（如三叉戟 / 双前锋 / 双后腰 / 双10号 / 三中卫+双翼卫），决定了**你天然擅长哪些区域指令与球员行为被动**。
> 2. **战术维度（球权与节奏理念）**：6 大打法决定了丢球、拿球、推进、防守的核心规则，各自长出对应的**核心行为被动、前/中/后三区双刃剑指令（带副作用与 3 颗卫星演化）、以及招牌主动技**。
> 3. **阵型 × 战术交叉融合（18 大真实/邪道流派延伸）**：当「防线体系/具体阵型」与「战术打法」在星盘中连通融合时，延伸出**专属足坛流派奇点、指令质变与主动技联动**——甚至允许“5后卫×高压”“3后卫×传控”等反直觉邪道 BD！

## 一、底层因果链总览

  • 4后卫(8阵)：均衡边卫、双腰、双锋、圣诞树     • 传控 / 高压 / 两翼 / 反击 / 铁桶 / 均衡
  • 3后卫(4阵)：三中卫 + 双翼卫 + 中场人数优势   • 每打法自带：核心被动 + 3条三区双刃剑指令
  • 5后卫(4阵)：五人防线 + 禁区厚度 + 快反纵深     (每条挂3颗卫星减副作用/质变) + 2个招牌主动技
                    │                                       │
                    └───────────────┬───────────────────────┘
                                    ▼
              [C. 阵型 × 战术 交叉融合：18 大流派延伸 (3体系 × 6打法)]

## 二、阵型维度（3 大防线体系 × 16 阵型各自自带什么？）

> 阵型决定“手里有什么兵”。在星盘内环，点亮某个体系与具体阵型，直接演化出**对应岗位的球员行为被动**与**三区指令槽位特权**。

### 1. 四后卫体系（`4-back` · 均衡控制与肋部协同 · 共 8 阵）
* **体系原生被动**：`四卫防线协同`（LB/RB 与双 CB 保持防线平行，防线造越位判定成功率 `+12%`，边卫套上深度 `+2m`）。
* **体系原生指令演化**：解禁后场指令变体——四卫同步前压造越位时，副作用风险自动 `-15%`。

|---|---|---|---|---|

## 三、战术打法维度（6 大流派各自自带什么？）

> 战术打法决定“怎么踢球”。每个打法自带：**2 条体系行为被动** + **3 条三区双刃剑指令（前/中/后各 1 条，每条挂 3 颗卫星改造点）** + **2 个招牌子弹时间主动技**。

### 1. 传控渗透（`tiki_taka` · 控球呼吸与短传撕裂）
* **打法自带被动**：
  1. `【传控体能呼吸】`：每连续完成 6 脚成功短传，全队自动回体 `+1.5%`。
  2. `【节拍器抗压出球】`：中后场短传精准度与抗逼抢冷静 `+8`。
* **打法自带 3 条三区双刃剑指令（20'/45'/70' 拐点点对应草皮下达）**：
  * **前场《肋部三角渗透》**：前场亮青色短传连线；短传+12、盘带+10、肋部穿透大增。**副作用**：节奏偏慢，前锋丢球后回防速度 `-8`。
    * *卫星演化*：A 消除回防速度惩罚 / B 禁区前造任意球率 `+30%` / C 质变·前场连续 5 脚传递后下脚射门必射正。
  * **中场《慢节奏倒脚控场》**：中场亮青色控球网格；传球+12、冷静+10，全队每 5 分钟回体 `+4%`。**副作用**：向前直塞意愿大幅下降，进攻停滞。
    * *卫星演化*：A 保留正常向前直塞意愿 / B 回体提至每 5 分 `+6%` / C 质变·控球超 60% 时对手全队体能加速流失。
  * **后场《后场从容出球》**：后场亮青色出球三角；后卫+门将传球+14、冷静+12，免疫对手高位逼抢。**副作用**：后场短传被极限断球时极易在禁区前直接送礼。
    * *卫星演化*：A 极限失误率大幅降低 / B 成功破逼抢后中场传球+8 / C 质变·破逼抢成功立刻全队推进提速 `+15%`。
* **打法自带招牌主动技（F 键）**：
  1. **《手术刀直塞》**（前场渗透瞬间：强制穿透直塞；A 无视越位 / B CD -3分）
  2. **《游龙突破造任意球》**（前场持球被包夹：强行突破赢前场黄金任意球；A 任意球 xG +35% / B 令犯规后卫吃黄牌）

### 2. 高位逼抢（`gegenpress` · 疯狗反抢与空间窒息）
* **打法自带被动**：
  1. `【六秒反抢法则】`：丢球后 6 秒内逼抢半径 `+4m`，解锁最多 3 人同时合围。
  2. `【前场压迫威慑】`：对手后卫在己方半场持球时冷静 `-6`，更容易被迫开大脚失误。
* **打法自带 3 条三区双刃剑指令**：
  * **前场《全线压上围攻》**：前场亮红色围攻热区；锋线+中场射门+10、禁区抢点 `+2` 人、防线整体前压。**副作用**：身后留出大片空当，对手直塞反击成功率 `+30%`。
    * *卫星演化*：A 对手直塞威胁减半 / B 射门加成提至 +14 / C 质变·前场每赢 1 次角球全队气势 +15%。
  * **中场《疯狂贴身绞杀》**：中圈亮红色合围雷达；中场抢断率 `+25%`、逼抢半径 `+5m`。**副作用**：中场体能消耗 `+70%`，犯规与吃黄牌率 `×1.8`。
    * *卫星演化*：A 额外体能消耗减半 / B 移除犯规吃牌惩罚 / C 质变·每次成功抢断反哺全队 `+2%` 体能。
  * **后场《造越位高位陷阱》**：后防线亮红色激光越位线；高频吹掉对手直塞单刀，极大压缩空间。**副作用**：一旦反越位失败，对手直接获得高 xG 单刀。
    * *卫星演化*：A 越位成功率再 +15% / B 失败时门将出击扑救 +12 / C 质变·每成功造越位 1 次立刻触发 1 次快攻。
* **打法自带招牌主动技（F 键）**：
  1. **《五秒窒息围抢》**（丢球瞬间：3 人合围强行瞬断并打乱对手节奏；A 对手迟滞 3 秒 / B 断球全队回体 +5%）
  2. **《造越位哨响》**（对手直塞单刀瞬间：防线同步前压吹停越位；A 吹停后立刻快发反击 / B 全队冷静 +10）

### 3. 两翼齐飞（`wing_play` · 极致宽度与边路传中）
* **打法自带被动**：
  1. `【边路角球制造机】`：边路下底传中被封堵时转化为角球的概率 `+30%`。
  2. `【禁区双点包抄】`：边路起球时额外 `+1` 名后点插上球员进入禁区争顶。
* **打法自带 3 条三区双刃剑指令**：
  * **前场《两翼走廊爆破》**：球场两侧亮金色冲刺走廊；边锋/边卫速度+12、传中倾向+12%、抢点+20%。**副作用**：中路保护真空，对手中路渗透传球成功率 `+20%`。
    * *卫星演化*：A 中路渗透惩罚减半 / B 角球产出率 +35% / C 质变·每次成功传中给中锋叠 +10% 下脚 xG。
  * **中场《转移调度撕扯》**：中场亮双向金色大转移弧线；大范围长传转移加速，强行拉散对手防线。**副作用**：长传失误风险上升，对手中场断球反击提速 `+15%`。
    * *卫星演化*：A 移除对手反击提速 / B 边路接球速度 +10 / C 质变·每次成功大转移削弱对手防线体能 -3%。
  * **后场《翼卫锁死边路》**：己方两条边路亮琥珀封锁区；极大压制对手边锋突破与传中。**副作用**：禁区中路保护人数减少，对手中路撞墙威胁 `+20%`。
    * *卫星演化*：A 中路保护惩罚减半 / B 边路断球率 +20% / C 质变·边路断球后立刻原地发动边路反击。
* **打法自带招牌主动技（F 键）**：
  1. **《边路爆破造角球》**（边路持球推进：高速下底强行传中造角球并激活禁区混战；A 禁区抢点 +2 人 / B 持续时间翻倍）
  2. **《空霸头球绝杀》**（边路传中/角球落点瞬间：高点强压中卫头球攻门；A 头球 xG +40% / B 叠 +1 反击威能）

### 4. 快速反击（`counter` · 诱敌深入与一剑封喉）
* **打法自带被动**：
  1. `【反击第一脚加速】`：由守转攻的 5 秒内，锋线与前腰速度 `+8`、直塞倾向 `+8%`。
  2. `【单刀大心脏】`：高速反击形成的禁区内射门冷静 `+8`。
